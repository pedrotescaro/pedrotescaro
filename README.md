### About me

Hi! I'm **Pedro Tescaro**, a **Fullstack Developer** passionate about technology and innovation.

I'm currently studying **Analysis and Systems Development (ADS)** at **FATEC Ferraz de Vasconcelos**, and I hold a technical degree in **Industrial Automation** from **IFSP**.

My focus is fullstack web development with **React, Node.js, TypeScript and Java / Spring Boot**. On the side, I also build some projects with **Flutter**, and I develop games with **Unity** and **GameMaker Studio 2**.
